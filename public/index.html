Safe Campus

Infrastructure Docker & guides CI/CD

Mon périmètre, réalisé seul : toute l'infrastructure Docker de l'équipe et les guides de pipelines CI/CD.

Docker Compose PHP 8.4 / Laravel Nuxt 4 PostgreSQL 17 CI/CD
  • Un seul compose orchestre quatre services et deux dépôts : back Laravel, front Nuxt, PostgreSQL, Adminer.
  • Image PHP 8.4 sur mesure : extensions pdo_pgsql, gd, intl, zip et Xdebug pour le debug pas à pas.
  • UID/GID de l'hôte injectés au build : plus de fichiers root dans les bind mounts, quel que soit le poste.
  • Démarrage conditionné par un healthcheck Postgres, limites CPU/mémoire par service, volumes nommés pour la base et les node_modules.
  • Le front démarre aussi seul, sans le back : l'équipe UI n'attend pas l'API.
  • Guides d'équipe : git flow feature/* → dev, format de commit imposé, conventions back et front documentées.
