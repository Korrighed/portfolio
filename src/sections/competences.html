02 — Compétences

Ce avec quoi je travaille

Compétences

  • Mettre en place l'environnement de dev d'une équipe et le documenter pour qu'il tourne sur tous les postes.
  • Travailler en git flow : branches de feature, revue avant merge, messages de commit normalisés.
  • Écrire la doc technique : README d'installation, conventions de code, guides de pipeline.
  • Intégrer une API tierce de bout en bout : authentification, cache, gestion des erreurs et des secrets.
  • Modéliser des données et la logique métier avant de coder l'interface.
  • Tenir une grille et une échelle typographique cohérentes d'un écran à l'autre.
